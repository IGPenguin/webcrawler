## ⚔️ Stay Dead
### 🖤 About this project
<b>Stay Dead is a free browser roguelike RPG.</b> No installation ➞ 🕹️ <b>[Play instantly on any device!](https://igpenguin.github.io/stay-dead)</b><br> Fight, talk, fish, and blunder your way through the corrupted world, growing stronger with every death. Unlock new content each run, dominate the <b>online leaderboard</b> and conquer the branching endgame.<br>

## 🤘 Support
<b>📣 [Send feedback](https://forms.gle/FJmHN9FL3ks65trv5)</b> to leave rating and suggest improvements.<br>
<b>📝 [Create issues](https://github.com/IGPenguin/stay-dead/issues)</b> to report problems or request changes.<br>

## 🔒 Privacy
Anonymous gameplay telemetry and optional highscores are collected to improve the game.<br>
No personal data is stored — no emails, no real names, no IP addresses on our end. 

## 🏗 Development
Game logic is written in JavaScript, driven by .csv data and styled with css.<br>
No build step, no modules — load order in `index.md` is the dependency chain.<br>
<br>
💻 Deploy with `deploy.sh` to install gems, free port 4000, serve and open the browser.<br>
