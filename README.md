# 💀 Stay Dead
## 🖤 About this project
<b>Stay Dead is a free browser roguelike RPG.</b> No installation ➞ 🕹️ <b>[Play instantly on any device!](https://igpenguin.github.io/stay-dead)</b><br>

**⚔️ Fight**, **💬 Talk**, **🎣 Fish**, and more... to blunder your way through the corrupted world, growing stronger with every death.<br>
Recall **🧩 Memories** each run to unlock new content. Dominate the online **🪦 Reckonings** and conquer **the branching story endgame**.<br>

## 📕 Codex of the Damned
**If you are stuggling**, read the **[📕 Codex of the Damned](WIKI.md)**.<br>
It's a spoiler-free overview of the basic survival tips.

## 🔒 Privacy
**Anonymous gameplay telemetry and optional highscores** are collected to improve the game.<br>
No personal data is stored: no emails, no real names, no IP addresses. 

## 🏗 Development
The core game logic is written in JavaScript, populated with .csv data and styled with Jekyll and CSS.<br>
No build steps, no modules, the load order in `index.md` is the only dependency chain.<br>

💻 Deploy with `scripts/deploy.sh` to install gems, free port 4000, serve and open the browser.<br>
