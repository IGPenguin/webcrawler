## 🖤 About this project
### ⚔️ Webcrawler
Another text-based rougelike RPG, this one is written in JavaScript + driven by .csv data.<br>
<b>→ [Play in the browser!](https://igpenguin.github.io/webcrawler)</b> _(optimized for iPhone)_<br>
